What is GPT Image 2?

GPT Image 2 is OpenAI's flagship image model with native 4K output, precise text rendering (posters, UI screenshots, comic speech bubbles), and strong instruction following. It handles JSON and natural-language prompts across photography, UI, infographics, posters, and consistent characters.

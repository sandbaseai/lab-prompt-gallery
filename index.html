What is GPT Image 2?

GPT Image 2 是 OpenAI 推出的旗舰级图像生成模型,具备原生 4K 输出、 精准文字渲染(海报、UI 截图、漫画对话框)和强指令遵循能力。 它能稳定处理 JSON / 自然语言两种 prompt 范式,在摄影、UI、信息图、海报、 角色一致性等场景表现尤其出色。

本站点从 awesome-gpt-image-2、 canghe.ai 镜像库 与社区推特采集 prompt, 全部按 Brutalism 分类聚合,支持一键复制、二创、二次分发。

Common Questions

What is GPT Image 2?

OpenAI 的新一代原生图像生成模型。支持 4K 输出、精确文字渲染、强大的指令遵循, 可生成摄影、UI 截图、海报、漫画、信息图等多种风格图像。

Where do these prompts come from?

数据主要来自 freestylefly/awesome-gpt-image-2 社区开源仓库和 canghe.ai 镜像。所有 prompt 版权归原作者所有,仅用于学习与二次创作。

How do I use these prompts?

点开任意卡片 → "Copy" 完整 prompt → 粘贴到 MeiMind、ChatGPT 或任意支持 GPT Image 2 的工具中 → 调整参数 → 生成。鼓励基于现有 prompt 进行 remix 与扩展。

Can I submit my own prompt?

当然。点击右上角 "Submit Prompt",在 GitHub 仓库提一个 PR,我们会在 24h 内审合并入。 高质量 prompt 会被推上 Trending 区。

Is this free?

100% free,无注册、无水印、无追踪。本站所有内容遵循对应源仓库的 License(CC-BY-4.0 / MIT)。
